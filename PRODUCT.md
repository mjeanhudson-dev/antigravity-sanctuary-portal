## Users

## Product Purpose

The **Antigravity Multi-Agent Hub & Bounty Board Portal** serves as the central command surface and visibility layer for a multi-agent engineering network. It surfaces project status, active task claims, domain-specific module indices, verified milestone handoffs, and venture incubator roadmaps in a single, high-density, real-time dashboard.

## Positioning

Unlike conventional agile boards (Linear, Jira, Trello) or static Markdown trees, the Antigravity Hub is purpose-built for high-throughput human-AI co-development. It tightly pairs human architectural governance with machine-readable atomic claiming, cryptographic artifact verification, and domain overlay tagging to solve multi-agent context amnesia and token churn.

- Accommodates multiple AI harness interfaces (Antigravity IDE, Claude Code, Cursor, Codex CLI, Gemini CLI).
- Bridges low-level C++/Win32 systems engineering with higher-level SaaS venture tracks.

## Capabilities and Constraints

### Capabilities
- **Central Bounty & Claim Ledger**: Real-time filtering, inspection, and status management (`OPEN`, `CLAIMED`, `IN_PROGRESS`, `BLOCKED`, `COMPLETED`, `SUPERSEDED`).
- **Domain Overlay Taxonomy**: Fast cross-project discovery across hardware HID, XInput proxying, 1€ adaptive filtering, motion IMU fusion, telemetry visualizers, and PINPOINT test harnesses.
- **Chronological Milestone & Handoff Ledger**: Audit trail of every breakthrough, dependency graph, and agent handoff report.
- **Venture Incubator Portal**: Track and model revenue wedges, architectural moats, and R&D pipelines (OmniChorus/PulseDeck, DualSense Motion Steering, etc.).
- **Registry & Scaffolding Automation**: One-click onboarding for newly initialized subprojects via standardized repository templates.

### Constraints
- **Hardware & Ground-Truth Verification**: No synthetic tests or speculative mocks may supersede verified hardware test passes (e.g. 114 PINPOINT checks).
- **Zero Stock File Tampering**: Cloud save profiles and stock game/system configurations remain untouched; all non-linearities are handled via inverse pre-compensation.
- **Zero Token Waste / Anti-Regressive**: Strict verification prior to codebase exploration to avoid redundant file-reading loops.
- **Deterministic Deployment Parity**: Cryptographic SHA256 parity maintained between working copies, desktop staging, and target install directories.

## Product Principles

1. **Hardware & Ground Truth Over Synthetic Mocks**: Prioritize deterministic physical verification and concrete logs over synthetic test suites or unanchored assumptions.
2. **Atomic Ownership & Zero Overwrite**: Every task, milestone, and claim must be distinctly owned, preventing conflicting agent overwrites.
3. **High-Density, Fast-Scan Information**: Present critical signals, statuses, and links cleanly and densely so human architects and agents evaluate state in seconds.
4. **Resilient Local-First Continuity**: Built on durable, file-backed schemas and reproducible local scripts that thrive offline or across diverse harness restarts.

## Accessibility & Inclusion

- Adherence to WCAG AA contrast standards across all UI themes.
- Full keyboard navigation across data tables, filter pills, and detail drawers.
- Strict reliance on iconography accompanied by text labels or unambiguous tooltips; status is never conveyed by color alone.
- Monospace typographic treatments for hashes, paths, domain tags, and telemetry metrics to guarantee readability.
